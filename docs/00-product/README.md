## Purpose

Defines **what SDC is** and **what the platform is for**, independent of any implementation. Every other section (requirements, domain, architecture) must be consistent with these documents.

SDC is a **non-profit volunteer technology community**. It is not a commercial SaaS product: there are no customers, subscriptions, pricing plans, tenants or billing. Vocabulary from commercial products must not leak into SDC documentation or code.
