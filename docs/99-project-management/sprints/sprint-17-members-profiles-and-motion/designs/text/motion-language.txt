 إعادة التشغيل 
 معاينة «تقليل الحركة» 
 حركة هادئة،
تُحسّ ولا تُلاحظ
 مفردات حركة واحدة للموقع العام ولوحة التحكم. ستة عشر نمطاً، كلٌّ بمدته وتوقيته من رموز الحركة، وبنسخته عند تقليل الحركة.
 المحتوى أولاً كل شيء في HTML من البداية. الحركة تزيّن ولا تؤخّر. 
 تحويل وشفافية فقط transform و opacity. لا شيء يغيّر التخطيط، و CLS صفر. 
 باتجاه القراءة «التالي» يأتي من اليسار في العربية ومن اليمين في الإنجليزية. 
 نسخة هادئة دائماً prefers-reduced-motion يوقف الحركة ويُبقي التلاشي فقط. 
 الرموز
 المدد 
 instant 100ms 
 fast · تفاعل صغير 160ms 
 base · دخول وخروج 240ms 
 slow · مسافة كبيرة 400ms 
 counter · العدّ 1200ms 
 التوقيت 
 ease-out · الدخول 0.2, 0, 0, 1 
 ease-in · الخروج 0.4, 0, 1, 1 
 ease-standard · التحريك 0.2, 0, 0.2, 1 
 النوابض والتتابع (motion) 
 spring.soft stiffness 380 · damping 34. اللوحات والنوافذ. spring.snappy stiffness 520 · damping 38. الشرائح والمفاتيح. stagger 40ms لكل عنصر، 8 عناصر حداً أقصى. distance 12px للنصوص، 16px للبطاقات، 24px للأقسام والخطوات. 
 القاعدة: MotionConfig reducedMotion="user" يغلّف الواجهة العامة، فيلتزم كل نابض بإعداد المستخدم تلقائياً.

 اضغط «إعادة التشغيل» لرؤية الحركة مرة أخرى. M4 و M9 و M10 تفاعلية.
 M1 دخول الصفحة CSS 
 زر
 المتى أول عرض للصفحة، فوق الطيّة فقط الحركة opacity 0→1، translateY 12px→0 المدة base 240 · ease-out · تتابع 60ms، 5 عناصر حداً أقصى أين عنوان الصفحة، الوصف، الأزرار 
 تقليل الحركة: يظهر كل شيء فوراً بلا حركة.
 M2 الظهور عند التمرير CSS 
 المتى دخول القسم إلى الشاشة الحركة opacity، translateY 24px→0 المدة animation-timeline: view()، range entry 0% → cover 22% أين عناوين الأقسام والبطاقات الكبيرة 
 تقليل الحركة: المحتوى ظاهر من البداية. والمتصفح الذي لا يدعم view() يعرضه ظاهراً أيضاً.
 M3 تتابع القوائم CSS 
 المتى أول عرض للشبكة، وتحميل المزيد الحركة opacity، translateY 16px المدة base 240 · خطوة 40ms · حد 8 عناصر (320ms) أين بطاقات الأعضاء والفعاليات والمقالات 
 تقليل الحركة: بلا تتابع وبلا حركة.
 M4 رفع البطاقة CSS 
 مرّر أو ركّز هنا

 تقليل الحركة: يتغيّر لون الحدّ فقط، بلا رفع ولا تكبير.

 M8 اللوحة السفلية motion

 تقليل الحركة: تظهر وتختفي بالشفافية، والإغلاق بالزر فقط يبقى متاحاً دائماً.

 تقليل الحركة: نقطة ثابتة بلا نبض.
 أين يُستخدم كل نمط
 أين يُستخدم كل نمط النمط الرئيسية الفعالية الأعضاء الملف المقالات اللجان انضم لوحة التحكم M1 دخول الصفحة M2 الظهور عند التمرير لا لا M3 تتابع القوائم لا لا لا M4 رفع البطاقة لا M5 شريط الأعضاء لا لا لا لا لا لا لا M6 العدّ التصاعدي لا لا لا لا لا M7 النوافذ لا لا لا لا لا M8 اللوحة السفلية لا لا لا لا M9 إعادة ترتيب الشبكة لا لا لا لا لا M10 الصورة إلى الملف لا لا لا لا لا لا M11 الانتقال بين الصفحات لا M12 خطوات المعالج لا لا لا لا لا M13 إضافة مهارة لا لا لا لا لا لا لا M14 امتلاء الاكتمال لا لا لا لا لا لا M15 الإشعار المنبثق لا لا لا لا M16 نبض الحالة لا لا لا لا لا 
 الرئيسية دخول البطل M1، أرقام المجتمع M6، الأقسام M2، الفعاليات القادمة M3 + M4، شريط الأعضاء M5. نبض «جارية الآن» على فعالية واحدة فقط.
 الأعضاء والملف الدليل: M3 أول مرة ثم M9 عند كل فلتر. فتح ملف: M10 للصورة والاسم ثم M2 للأقسام. الفلاتر على الجوال M8.
 لوحة التحكم أهدأ من الموقع العام: لا ظهور عند التمرير ولا عدّ. النوافذ M7، المعالج M12، الإشعارات M15، المحرّر M13 و M14.

 --ease-out: cubic-bezier(0.2, 0, 0, 1);
 --ease-in: cubic-bezier(0.4, 0, 1, 1);
 --ease-standard: cubic-bezier(0.2, 0, 0.2, 1);

@keyframes m-rise { from { opacity: 0; transform: translateY(var(--m-y, 12px)); } }
/* M1 page enter: server-rendered, no JS */

.m-enter > :nth-child(2) { animation-delay: 60ms; }
.m-enter > :nth-child(3) { animation-delay: 120ms; }
/* M2 scroll reveal: only where supported, content visible otherwise */
@supports (animation-timeline: view()) {
 .m-reveal { --m-y: 24px; animation: m-rise linear both;
 animation-timeline: view(); animation-range: entry 0% cover 22%; }
}
/* M3 stagger: the server sets --i on each item (0..7) */
.m-stagger > * { animation: m-rise var(--duration-base) var(--ease-out) both;
 animation-delay: calc(min(var(--i, 0), 7) * var(--stagger-step)); --m-y: 16px; }
/* M4 card hover */
.m-lift { transition: transform var(--duration-fast) var(--ease-out),
 box-shadow var(--duration-fast), border-color var(--duration-fast); }
.m-lift:is(:hover, :focus-within) { transform: translateY(-4px);
 box-shadow: var(--elev-1); border-color: var(--border-accent); }
/* M6 count-up */
@property --m-n { syntax: '<integer>'; initial-value: 0; inherits: false; }
.m-count { counter-reset: n var(--m-n); animation: m-count var(--duration-counter) var(--ease-out) both; }
.m-count::after { content: counter(n); }
@keyframes m-count { from { --m-n: 0; } to { --m-n: var(--m-to); } }
/* M16 live pulse */
.m-live { animation: m-pulse 1.8s ease-in-out infinite; }
@media (prefers-reduced-motion: reduce) {
 .m-enter > *, .m-reveal, .m-stagger > *, .m-count, .m-live { animation: none; }
 .m-lift:is(:hover, :focus-within) { transform: none; box-shadow: none; }
 .m-count { --m-n: var(--m-to); }
}
