## 1. Scope
Every public page on Design System v2 ([ADR-014](../../90-decisions/ADR-014-public-redesign-design-system-v2.md)): new header and footer, Home, event page with a registration dialog, calendar export, check-in, members directory and profile with per-field consent (no contact details in the HTML), events list, articles, committees index, About, Join, certificate verification, privacy and 404. The auth pages use a split layout without site chrome. The dashboard shares the tokens and moves slightly.
