# Reference screenshots: Tuwaiq websites

These screenshots are **design references only**, taken by the owner from three public sites:
the academy (`tuwaiq.edu.sa`), the student club (`club.tuwaiq.edu.sa`) and the learning platform (`satr.tuwaiq.edu.sa`).
Use them to study layout, type scale, spacing, shapes, motion and the sign-in layout.
**Do not copy** their logos, photographs, illustrations, names or copy into SDC. Their brand belongs to their owners.

## Notes for designers

- Several screenshots show a logged-in user's name in the header. Ignore it; SDC's header design is its own.
- The sign-in page (`11`) has no header and no footer. SDC's auth pages should follow this layout, not the public header.
- Type: headlines are very large (about four to five times the body size); body text is comfortable with generous line height.
  Arabic and Latin are set in one family pairing.
