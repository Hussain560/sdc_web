The SDC logo files, used exactly as supplied (never redrawn, recoloured or placed on a photo).

- `sdc-wordmark-on-dark.png`: light-ink horizontal wordmark (transparent) for dark surfaces.
- `sdc-wordmark-on-light.png`: full-colour wordmark for light surfaces. It has a baked mint background (#F2F9F4) and wide padding: place it on `canvas` or `band` in light, or blend with `mix-blend-mode: multiply`. A transparent master is requested (Q-041).
- `sdc-vertical-on-dark.png`: vertical lockup for the dark footer. A light variant is needed.
- `sdc-mark.png`: the mark alone (transparent), extracted pixel-for-pixel from the repository's `sdc-logo-mark.svg`, which only wraps this raster. Favicon, the auth phone strip, official-post avatars.
- Clear space: one mark-dot height on every side. Minimum height: 28px (wordmark), 24px (mark).
