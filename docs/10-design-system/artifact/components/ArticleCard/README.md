# ArticleCard

An article in a list or grid: topic, title, 2-line excerpt, author, date and reading time.

- Optional 16:9 cover above the topic chip. Excerpt clamps at 2 lines in `text-muted`.
- Consumer provides: the published article's title, excerpt, topic, author (public profile only), date, reading time.

Full spec: `docs/10-design-system/components.md` in the repo.
