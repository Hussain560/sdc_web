# Logo

The SDC wordmark, vertical lockup and mark, used exactly as supplied and never redrawn or recoloured.

- **On dark surfaces:** `assets/Logos/sdc-wordmark-on-dark.png` (light ink). **On light surfaces:** `assets/Logos/sdc-wordmark-on-light.png` (full colour; it has a baked mint background, so place it on `canvas` or `band` in light, or blend with `mix-blend-mode: multiply`). Swap by theme with the `theme-dark-only` / `theme-light-only` classes.
- The vertical lockup (`sdc-vertical-on-dark.png`) is for the footer in dark. The mark (`sdc-mark.png`) is for the favicon, the auth phone strip and avatars of official SDC posts.
- Clear space = the height of one mark dot on every side. Minimum height: 28px wordmark, 24px mark.
- The logo links home with `aria-label` = "المجتمع السعودي للمطورين — الرئيسية" / "Saudi Developer Community — home".
- The consumer provides nothing but the size; never add effects, outlines or tints.

Full spec: `docs/10-design-system/components.md` in the repo.
