# IconButton

A 44px round button with only an icon; its accessible name is required.

- Variants: `ghost` (default), `secondary` (outlined circle, used as the round arrow on directory cards), `primary`.
- The `aria-label` names the action in the page language; a tooltip shows the same text on hover and focus.
- Consumer provides: `label`, the icon, the variant.

Full spec: `docs/10-design-system/components.md` in the repo.
