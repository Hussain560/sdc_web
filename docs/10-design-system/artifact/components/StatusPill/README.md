# StatusPill

A badge with a required icon and a fixed event-status vocabulary, so status is never colour alone.

- Open (success), closes soon (warning), full · waiting list (warning), registered (accent), happening now (info), finished (neutral), cancelled (danger), registration opens soon (neutral).
- Consumer provides: the status key; the label and icon come from the vocabulary.

Full spec: `docs/10-design-system/components.md` in the repo.
