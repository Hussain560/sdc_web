# StatsRow

Key figures: large `t-stat` numerals in `signal` with a muted label, separated by hairlines.

- **Real data only** (a query or site settings). With no data the row is not rendered — never "0+" or invented numbers. The zeros shown here are labelled placeholders.
- Counts up once on reveal; the final value is in the DOM from the start; reduced motion shows it immediately.

Full spec: `docs/10-design-system/components.md` in the repo.
