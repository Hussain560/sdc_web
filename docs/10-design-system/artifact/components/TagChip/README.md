# TagChip

A topic label (`static`) or a filter toggle (`button` with `aria-pressed`).

- Selected filter: `accent-soft` fill, `on-accent-soft` text, a check icon. Removable chips carry an X with the label "Remove filter: …".
- Consumer provides: the label, pressed state and handler for filters.

Full spec: `docs/10-design-system/components.md` in the repo.
