# Badge

A small non-interactive label with a soft tone fill.

- Tones: `neutral`, `accent`, `success`, `warning`, `danger`, `info`; each uses its `-soft` fill and its own text token (never `text-muted` on a soft fill).
- Text is always present; colour is reinforcement.
- Consumer provides: the text and the tone.

Full spec: `docs/10-design-system/components.md` in the repo.
