# TextLink

A link styled for text: always underlined inside paragraphs, underlined on hover when standalone.

- Colour `accent-text` (5.1:1 or better in both themes). External links add an external icon and "(opens in a new tab)" for screen readers.
- Consumer provides: `href` (via the i18n `Link`), the text.

Full spec: `docs/10-design-system/components.md` in the repo.
