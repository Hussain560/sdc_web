# SegmentedToggle

Switches between 2–4 views of the same content; a radio group in a pill track.

- Selected segment: `accent` fill with `text-on-accent`. Arrow keys move the selection and follow the reading direction.
- Use: why-join (for members / for partners), events (upcoming / past).
- Consumer provides: the options, the value, `onChange`, an accessible group label.

Full spec: `docs/10-design-system/components.md` in the repo.
