> **Method.** The notes come from the owner's screenshots, taken at about 1440 CSS px wide (2× pixel density). Sizes are measured from the images and rounded to the nearest 2 px, so treat them as **approximate**. `club.tuwaiq.edu.sa` refuses automated fetching (robots), so it wasn't crawled. The screenshots don't show motion, the mobile layouts or a single event page. Those rows say *not captured*, and the SDC pattern for them is our own.
>
> **Do not copy.** The logos, photographs, 3D illustrations, names, copy, the purple palette and the "two overlapping squares" heading motif belong to Tuwaiq. SDC uses its own mark, its green palette and its own motif (see [shape and motif](./foundations/layout-and-shape.md#7-motif-the-crossing)).

## 4. What SDC takes, by area

| Area | SDC direction |
| ---- | ------------- |
| Header | A floating, inset bar (`--radius-xl`, 1 px border, `--surface` at 85% with backdrop blur), nav grouped in a pill, one primary action at the inline-end. On phones: logo + menu button + a bottom sheet. |
| Hero | Headline-led. Display size ≈ 4× body. One primary action plus at most one quiet link. The SDC mark art (`hero-logo.png` / `light-mode.png`) on the opposite side. An optional announcement strip above the hero for the next event. |
| Figures | A stats row (3–4 numerals with dividers) inside the hero, and a stats bento on About. Real data only. |
| Sections | Title + one-line lede + outline action at the opposite end. The SDC "signal dots" glyph (two dots from the mark) before the title. **No** eyebrow labels. |
| Rhythm | 64 px (phone) / 96 px (tablet) / 120 px (desktop) between sections; tinted bands with `--radius-2xl` for alternate sections. |
| Cards | 20–24 px radius, a hairline border, no resting shadow, a hover lift with the green glow. The title sits **below** the image, never on it. A meta row with icons. A round arrow action for directory cards. |
| Lists | One filter row (search + selects); filters become a bottom sheet on phones. |
| Why join | A bento of 4 benefits + a tall CTA card; a segmented toggle (for members / for partners). |
| FAQ | An accordion with an open-item tint and a plus/minus disc. |
| Sign-in | No site chrome. A split screen with the brand panel (the SDC mark and the motif pattern on deep green) and the form side. **"Apply for membership" replaces "create account"** (ADR-013). |
| Forms | Filled fields (`--field`) with a visible 1 px strong border (3:1, unlike the reference's borderless fields), 48 px tall, labels above. |
