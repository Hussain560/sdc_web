# 20 — Suggested Additions

Each proposal says what it is, why the community needs it, and whether it's needed **for launch** of the redesign or can come **later**. None of them invents content: each needs owner copy or real data, listed in the open questions.

| # | Proposal | Why (one or two sentences) | Priority |
| - | -------- | -------------------------- | -------- |
| A-1 | **Committees index `/committees`** ([08](./08-committees.md)) | The home "community sections" tiles point nowhere today. One page explains how SDC is organised and gives every committee a door. | Launch |
| A-2 | **Membership journey** on `/join` (5 steps) | Membership opens in windows, so people need to see the whole path (apply → review → result → activate → committee) to trust it and come back. | Launch |
| A-3 | **"Add to calendar"** (`.ics` + Google link) for events and for the next intake opening | The cheapest way to turn interest into attendance; no personal data is collected. | Launch |
| A-4 | **Announcement strip** on the home page | Puts the one open registration in front of everyone without a pop-up. | Launch |
| A-5 | **FAQ page `/faq`** | Collects the questions repeated on home, events and join in one place, grouped (membership, events, certificates). Each group links back. | Launch (short), grows later |
| A-6 | **Search `/search`** (Q-023) | The header search led to a 404; one results page across events, articles and listed members (only public views). Until it exists the search icon is hidden. | Later |
| A-7 | **How we work** section on About | A 3-step picture (committees run events → members attend and contribute → certificates and articles record it) answers "how do I get involved" for partners and students. | Launch |
| A-8 | **Highlights / gallery `/highlights`** | Past events with real photos show what SDC actually does better than any lede. It needs consented photos (M-70) and a gallery table. | Later |
| A-9 | **Press and brand kit `/brand`** | Partners and universities keep asking for the logo; one page with the approved files, clear-space rules and colours prevents misuse. Needs the SVG masters (Q-041). | Later |
| A-10 | **Partner tiers `/partners`** | Explains how organisations can support SDC (hosting, mentoring, sponsorship) with a contact action, and lists current partners by tier. Tiers are the owner's decision. | Later |
| A-11 | **Speaker / mentor call** section on About or Events | A visible "share your expertise" path grows the pool of presenters without extra admin work (a link to a form the owner chooses). | Later |
| A-12 | **Member spotlight** on the home page | A rotating real member story, **only with written consent**. Adds a human face once the content exists. | Later |
| A-13 | **Event series pages** (e.g. a monthly meetup) | Recurring formats deserve one stable URL with past and next editions. Needs a `series` field. | Later |
| A-14 | **Status of my registration** link in e-mails | A tokenised link so guests (no account) can see or cancel their registration, instead of replying to an e-mail. Needs a token per registration. | Later |
