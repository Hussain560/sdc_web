# منصة المجتمع السعودي للمطورين (SDC) 🚀

تطوير واجهة المستخدم الخاصة بموقع المجتمع السعودي للمطورين باستخدام React ولغات الويب الأساسية.

## 📁 هيكلية المشروع (Architecture)

تم تقسيم المشروع إلى مكونات مستقلة (Modular Components) لسهولة التطوير والتعديل:
- **Header**: شريط التنقل والشعار.
- **HeroSection**: الواجهة الرئيسية الترحيبية.
- **ArticlesSection**: قسم المقالات وأحدث الفعاليات.
- **MembersSection**: عرض أعضاء المجتمع والتفاعل.
- **Footer**: التذييل وروابط التواصل.
